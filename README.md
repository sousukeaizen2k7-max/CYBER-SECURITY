# CYBER-SECURITY
Linux-Security-Reconnaissance
Linux, Security Tools & Reconnaissance
Project Overview
This project focuses on learning Linux fundamentals, cybersecurity basics, reconnaissance techniques, and essential security tools. It provides practical experience in identifying network devices, analyzing network traffic, and understanding web application security in a controlled lab environment.

Objectives
Learn Linux commands, files, directories, permissions, users, and groups.
Understand passive and active reconnaissance.
Perform DNS and domain information gathering.
Learn network scanning and enumeration.
Practise using essential cybersecurity tools.
Build a controlled reconnaissance lab.
Document security findings and observations.
Tools and Technologies
Linux – Operating system and command-line fundamentals.
Nmap – Network discovery and port scanning.
Wireshark – Network traffic analysis.
Burp Suite – Web application security testing.
OWASP ZAP – Web vulnerability assessment.

Expected Outcome
By completing this project, we aim to understand basic cybersecurity concepts, gain practical experience with security tools, and learn how to identify and document potential security issues.

Safety and Ethical Guidelines
All practical activities will be performed only on personally owned systems, intentionally vulnerable lab applications, or systems for which permission has been granted.
